# Domain docs

AppForKids has one domain glossary at the workspace root in `GLOSSARY.md`. Architecture decisions live in `docs/adr/`.

Before exploring the app, read the glossary and any architecture decisions relevant to the work. Continue if either is absent. Use glossary terms in code, tests and issues. Flag terms that need a definition when they affect a decision. If a proposed change conflicts with an architecture decision, name that decision and describe what would need to change.
