# Fiche synthétique de P3 · Les synonymes

Transcription d’une fiche originale pour tester le parcours de création d’un jeu.

## Page 1

Relie le mot en gras au mot de même sens dans la colonne de droite. Tu peux remplacer le mot en gras dans chaque phrase pour vérifier.

Exemple. Mouna court **vite**. Mouna court **rapidement**.

| Phrase | Mots à relier |
| --- | --- |
| A. Sami est **content** de gagner. | débuter |
| B. Le spectacle va **commencer**. | beau |
| C. Ce dessin est **joli**. | heureux |

D. Le chat va **[mot illisible]**. La fin de la ligne et le mot à relier manquent dans la transcription.
