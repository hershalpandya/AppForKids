# Child selection and local data

The family app asks for a display name or nickname and keeps profiles in app-private storage on the device. It shows the chooser on each fresh launch. Names are trimmed, limited to 40 UTF-16 characters, must not contain control characters, and must be distinct ignoring case. Selecting another child immediately discards the current round. The arithmetic prompt is a simple parent check, not a security boundary. Worksheet previews remain separate and do not create profiles. These choices implement [issue #32](https://github.com/hershalpandya/AppForKids/issues/32), including its family decisions on distinct names, fresh launches and immediate switching.

Each profile has a random local ID. Deleting it removes that ID; reusing the name creates a new ID. The current app does not yet save per-child progress. Future progress storage must be keyed by that ID and removed atomically with the profile, including during recovery. If profile data cannot be read, the app does not overwrite it; a parent can retry by reopening the app or explicitly erase damaged profiles after a warning.

Uninstalling or clearing app data loses local profiles. The manifest disables Android backup and the Android 12+ data extraction rules exclude app data from cloud backup and device transfer. These are configuration choices, not proof of device behavior: backup and transfer have **not** been verified across supported Android versions or on the family tablet. Do not promise transfer exclusion until those checks are completed. Record device and OS versions and the actual restored data when testing. Neither accounts nor network access are needed for the feature.

The family app declares no Internet permission and has no app runtime library dependencies in its Gradle file. The only application log call found is a bundled-catalogue loading error, which does not include a child name. This source audit is not a verification of OS backup, transfer, or every distribution build. Recheck the packaged manifest and dependencies before release.
