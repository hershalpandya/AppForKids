# P1 starter game

On 2026-11-27, `hershalpandya/AppForKids@aff39d5` introduced **Les étoiles à compter**, an original French-language P1 activity. Its three questions practise counting stars one by one and identifying the total. The packaged game definition was versioned and independent of the Android view code so later worksheet drafts could use the same runtime. [Starter ticket](https://github.com/hershalpandya/AppForKids/issues/2) · [FW-B mathematics reference, p. 32](https://www.enseignement.be/fileadmin/portail_age/uploads/parcours_apprentissage/maternel_primaire_ordinaire/Organisation/Contenus_apprentissages_Maternel_Primaire/Referentiels/2022_REF_Mathematiques.pdf#page=32)

The activity was the first fixture for [Android APK testing](android-apk-testing.md).
